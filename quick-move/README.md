# Container Van Locator · Quick Move

A free, installable yard locator for laptop, desktop, Android phones, and tablets. This separate edition replaces the column-based Quick shift screen with step-by-step button choices for source bay/block, van, and destination bay/block. The original version remains available at the site root.

## Install on Android

Open `https://ennanlaganva-app.github.io/Container-van-locator/quick-move/` in Chrome on Android. Use the browser menu and choose **Install app** or **Add to Home screen**. The same link works on a laptop and desktop. This is a Progressive Web App; it does not require a paid service or a separate APK.

## Data

Both editions use the same browser storage on the same device, so the Quick Move edition sees the yard list already saved by the main app. Records stay local to that browser. Use **Share snapshot** to send a point-in-time copy; it is not live syncing.
